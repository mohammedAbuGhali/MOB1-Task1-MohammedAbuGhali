## Suggested setup

When adding the app, create or open an Android Studio project here. Android Studio can generate the Gradle wrapper, app module, and starter activity for the chosen template.

Once an Android project is added, typical local steps will be:

1. Open the project in Android Studio and complete Gradle sync.
2. Select an emulator or connected Android device.
3. Run the app from Android Studio, or use the project wrapper to build it.
